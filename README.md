# root-project

Monorepo scaffold for the tourism web workspace.

## Structure

- `apps/api-backend`: centralized backend
- `apps/tourist-frontend`: tourist-facing app
- `apps/admin-frontend`: admin portal
- `apps/vendor-frontend`: vendor portal
- `packages/database`: shared schema and DB connection logic
- `packages/shared-types`: shared API contracts
- `packages/ui-core`: shared design system
